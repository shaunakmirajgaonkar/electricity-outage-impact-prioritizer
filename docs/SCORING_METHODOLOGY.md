# Scoring Methodology

GridRelief Local uses a transparent weighted screening score from 0–100.

Higher values indicate greater potential impact from delayed restoration based on:
- hospital dependency
- water-supply dependency
- heat risk
- vulnerable-resident index
- critical-facility dependency
- outage duration
- population exposed
- road-access constraints
- recent outage frequency
- backup-power gap

The score is not an automatic restoration order and does not predict a guaranteed outage outcome.
