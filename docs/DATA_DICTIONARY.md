# Data Dictionary

| Column | Meaning |
|---|---|
| zone_id | Privacy-conscious operational zone identifier |
| zone_name | Demonstration zone name |
| latitude / longitude | Zone centroid for local analytics |
| hospital_dependency | Relative dependency on hospital/medical services |
| water_supply_dependency | Relative dependency on water infrastructure |
| heat_risk | Heat exposure index |
| vulnerable_resident_index | Relative concentration of residents needing additional support |
| critical_facility_dependency | Dependency on critical facilities |
| outage_duration_hours | Current outage duration |
| population_exposed | Approximate exposed population index |
| road_access_constraint | Access constraint index |
| backup_power_coverage | Estimated backup-power coverage percentage |
| recent_outage_count | Recent outage frequency |
